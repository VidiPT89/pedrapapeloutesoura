# ✊ Pedra Papel ou Tesoura — Rock Paper Scissors

> A classic Rock Paper Scissors game built with vanilla JavaScript.

Play against the computer in this simple yet fun game. Choose Rock (Pedra), Paper (Papel), or Scissors (Tesoura), and see the result instantly. The computer picks randomly, and each round displays both choices alongside the outcome.

## 📦 What's Inside

- ✊ Three-button interface for Rock, Paper, and Scissors
- 🤖 Random computer choice generation
- ⚡ Instant result calculation (Win, Lose, Draw)
- 📊 Live display of both player and computer choices
- 🎯 Standard game logic with all win/lose/draw conditions

- The game interface is in Portuguese: Pedra (Rock), Papel (Paper), Tesoura (Scissors).
- Results display as "Ganhaste!" (You win), "Perdeste!" (You lose), or "Empate!" (Draw).
- No external libraries or frameworks required.
